# DocReranker interactive walkthrough

Open the [live walkthrough](https://docreranker-classroom.litong1812.chatgpt.site), or open `index.html` in a browser while keeping this complete folder intact. No server, GPU, Python installation, or API key is needed to explore the saved examples.

Use the language switch to select English or Chinese. Progress through RAG, MMDocIR data, ColQwen2 retrieval, supervision construction, visual SFT and LoRA, evaluation, GRPO, and code practice. Interactions let you calculate scores and rewards, inspect real page images, and compare saved model outputs. Illustrative diagrams and synthetic exercises are labeled separately from recorded results.

To download models and data, run the implementation, or train your own reranker, follow the [student usage guide](../README.md). The Python implementation is in [`../src/docreranker/`](../src/docreranker/). The saved full-test results compare Base, merged SFT900, and SFT + GRPO512 on the same 1,658 questions.

The walkthrough works offline. The GitHub and resource links require an internet connection. The live site's share button preserves the selected language and chapter; an update notice appears when a new release is available.
