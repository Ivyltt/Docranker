# SFT 的完整测试结果

`outputs/flash-lite-reference4` 的最终 SFT 模型已完成全部 **313 篇文档、1,658 个查询**的独立测试。相对原始 Qwen2.5-VL-7B，Macro Recall@1 提高 **3.0881 个百分点**，MRR 提高 **0.030076**；在预先固定的查询配对 bootstrap 下，两项差值的 95% 区间均高于零。以下仅报告已完成的 Base 与 SFT 比较。

| 指标 | Base | SFT，最终 900 步 | SFT − Base | 差值的配对 95% CI |
| --- | ---: | ---: | ---: | ---: |
| Macro Recall@1 | 61.0927% | 64.1807% | +3.0881 个百分点 | [+1.2805, +4.9297] 个百分点 |
| Macro Recall@3 | 79.1375% | 81.9210% | +2.7835 个百分点 | [+1.6022, +3.8793] 个百分点 |
| Macro Recall@5 | 84.9166% | 84.9166% | 0 | [0, 0] |
| MRR | 0.758313 | 0.788390 | +0.030076 | [+0.017741, +0.042050] |
| nDCG@5 | 0.767047 | 0.788251 | +0.021205 | [+0.012930, +0.029686] |
| 格式失败回退率 | 96.9240%（1,607/1,658） | 0.0603%（1/1,658） | −96.8637 个百分点 | [−97.6493, −96.0193] 个百分点 |

区间使用同一批查询的配对差值，固定 **1,000 次有放回重采样、seed=42、百分位法**。本表的 Recall 是 macro：先为每题计算“命中 gold 页数 / 该题全部 gold 页数”，再对查询取平均。全部查询累计有 **2,107 个 gold 页标注**，按查询计数，并非去重后的页面数；未被检索召回的 gold 仍在分母中。Micro Recall 使用累计 2,107 作为总分母，SFT 的 Micro Recall@1 为 56.4309%。

**Recall@1 与 Hit@1 不同。** 一题有三个 gold，第一名只命中其中一个时，该题 Recall@1 是 1/3，Hit@1 是 1。SFT 在本测试上的 Hit@1 为 71.7129%，不能把它当作 64.1807% 的 Macro Recall@1。MRR 按第一张相关页的位置计分；nDCG 使用全部 gold 构造理想排序分母。所有 1,658 题均纳入统计，没有因格式失败或未召回 gold 而删题。

候选来自文档内 ColQwen2 检索，保持原始检索顺序输入模型，未注入 gold：**1,655 题各有 5 个候选，3 题各有 3 个候选，共 8,284 个候选页次**。三候选查询来自同一篇只有三页的法院文档，遵循 `min(5, 文档实际页数)`。重排序只改变这些候选的位置，因此 Recall@5 保持不变，不能找回候选集合之外的页面。Macro Recall@1 的逐题变化为 175 题改善、107 题退步、1,376 题不变。

Base 和 SFT 使用同一候选文件、图片与编号顺序、提示词和严格解析协议。统一设置为 BF16、SDPA、每批 1 个查询、greedy 生成、最多 256 个新 token，每页像素范围为 200704–401408。模型输入包含问题与页面图像，不包含 gold 标签或检索分数。有效输出须有非空 `<think>` 证据说明和唯一 `<answer>` 完整候选排列；失败时保留检索原序，并照常计入指标。Base 使用原始本地模型；SFT 使用同一模型加最终 LoRA adapter，processor 来自该 SFT 输出目录。

这 **1,658 题是完整 held-out test**，与用于预注册检查点选择的 **160 题 validation** 是不同集合。不能把两者的点值拼成一条模型提升曲线，也不能根据本测试结果重新调参或选择检查点。

SFT 使用冻结的 **7,200 条标注数据、1 个 epoch、900 次 optimizer 更新**；实际为两节点共 4 张 H100，global batch=8。用时采用以下明确范围，训练时间与单卡推理时间不能混算：
