**1,607 / 1,658 个输出不符合协议，格式失败回退率为 96.9240%。** 本表已把失败样本按既定规则回退到检索顺序，没有删除失败样本。因此指标接近检索基线，不能解释成模型已经能稳定重排序。后续必须同时比较排序指标和格式成功率。

协议要求一段非空 `<think>` 简短证据说明，随后一个 `<answer>`，其中是全部候选编号的完整排列。例如只输出 `[1]`、输出多组 think/answer，均不符合要求。Base 的实际输出中存在这些情况；失败率不能全部归因为生成截断，也不能仅靠失败率判断其阅读页面的语义能力。

三模型比较统一使用 BF16、SDPA、每页像素范围 200704–401408、每批一个查询、确定性生成和 256 个新 token 上限。1,655 个查询有五个候选，三个查询对应的文档只有三页，因此使用三个候选。所有 gold 页面均保留在指标分母中；评估未注入 gold。重排序保持候选集合不变，所以 Recall@5 与检索基线相同。

本次评估是原始模型基线，SFT 与 SFT+GRPO 的完整结果尚未产生。已有 Base 结果可以在新训练运行通过真实预检后，经 `scripts/reuse_base_evaluation.py` 验证模型、冻结推理代码、候选顺序及内容绑定，并重新计算指标后复用。迁移不会创建新训练成功记录。

## 独立复核与失败结构

完整独立复核见 [base-independent-review.json](../outputs/flash-lite/evaluation/base-independent-review.json)。复核重新调用旧 run 的冻结验证代码，逐条核对预测、原始回答、完整候选顺序、模型与推理参数，并重新计算所有正式指标及 1,000 次 bootstrap，结果与保存的 `base-metrics.json` 完全一致。1,658 个查询和全部 2,107 个 gold 页面与原评估 split 相符，4,663 个不同候选图像路径均存在；本次未重新检查图像语义内容。候选、预测、指标及完成元数据的 SHA-256 均未改变。

以下统计只针对 **1,607 个严格格式失败查询**，每种类别每个查询最多计一次；**类别可以重叠，不能相加当作总失败数**。

| 可见输出结构 | 查询数 |
| --- | ---: |
| 已闭合的整数答案数组缺少候选编号 | 1,177 |
| 其中只输出一个编号，如 `[1]` | 1,099 |
| 多个 `<think>` 块 | 524 |
| 至少缺少一种必需开/闭标签 | 334 |
| 其中没有 `<answer>` 开标签 | 330 |
| 多个 `<answer>` 块 | 40 |

| 某个答案数组包含越界编号 | 0 |

另外，95 个失败回答的某个 `<answer>` 块中确实存在完整排列，但整个回答违反单一解释块与单一答案块等格式要求。这只是结构诊断，没有把这些编号宽松提取后重新评分。

失败回答的可见文本重新分词后，中位长度为 **40 tokens**。其中 **1,266 个**标签成对闭合、以 `</answer>` 结束，且少于 240 tokens，仍因单编号或多块等协议问题失败。只有20个失败回答的可见文本达到250 tokens，其中14个恰为256。因此，96.9240%的回退率不能主要解释成统一256-token上限导致的截断。

以下例子只缩略证据说明，原始全文、query ID及回答SHA在报告中保留：

- `eval:PH_2016.06.08_Economy-Final.pdf:1`：41 tokens，完整结束于 `<think>…</think><answer>[1]</answer>`。该查询有五个候选，答案只选一页，未给出其余四页的排序。
- `eval:PH_2016.06.08_Economy-Final.pdf:0`：112 tokens，输出两个完整 `<think>` 块，再给出 `<answer>[2, 1, 5, 4, 3]</answer>`。排列完整，但解释块数量违反固定协议。
- `eval:earlybird-110722143746-phpapp02_95.pdf:0`：157 tokens，依次为五页各写一组 `<think>` 和单编号 `<answer>`。这是逐页评论结构，未按要求返回一个统一排列。
- `eval:fdac8d1e9ef56519371df7e6532df27d.pdf:4`：可见文本重新分词为256 tokens，第五段解释停在 `but does`，尚未写出答案，符合触及生成上限的表现。

原始预测没有保存生成 token ID 或停止原因；解码时还跳过了特殊 token。上述长度使用同一本地 tokenizer 对保存的可见文本重新分词，1,658条都能精确还原可见文本，但不能据此认定“恰好14条被截断”。可以确定的是，短且闭合的单编号、多块输出已经直接展示了协议未遵循。此处没有重新判断证据说明的语义正误，也不能从结构失败率推导页面阅读正确率。
